# Quiet Notes

Private, offline-first notes and voice memos for iPhone.

## Features

- Ideas, tasks, and standalone voice memos
- Saves directly in the iPhone browser
- Separate All, Ideas, Tasks, and Voice Memo lists
- Sequential filenames such as `[Idea-xxx] 26-Aug-27-01.md`
- Export to the iPhone share sheet, Files, or OneDrive
- Installable from Safari with Add to Home Screen
- No API key, account, database, or laptop connection

## Railway

Railway runs `npm start` and supplies `PORT` automatically. No environment variables are required.

After deployment, generate a public domain under the service's Settings → Networking section.

## Important storage note

Notes and recordings remain on the iPhone unless exported. Clearing Safari website data can remove unexported items.
